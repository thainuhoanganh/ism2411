### 2. 
Before this module, changes were either saved as backups with new filenames or you took the chance of breaking an already running script. Git lets you make small changes over time and track your progress with meaningful commit points. This workflow is safe for trying new things and changing code. If something goes wrong, it's easy to go back to a version that was working. 

### 3. 
One entry to include is '.DS_Store' (or editor-specific folders like '.vscode/settings.json'), which are specific to macOS and personal workspace settings. These files do not contribute to the program's logic and can clutter the repository or cause conflicts for other team members running on different operating systems.
